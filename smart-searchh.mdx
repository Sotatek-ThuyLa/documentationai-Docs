## **1. How to use Smart Search**

On the **Home** screen, click **Search** from the left sidebar menu.

### Search by keyword

If you know the note title or part of its content, simply enter a keyword into the search bar.

### Search using filters

You can narrow down the results by filtering by tags (the source used to create the note).

**Example:** If you only want to view notes created from YouTube or online meetings, simply select the corresponding Source. (_Recording, Youtube, Audio, Web Link, Document, Live Meeting._)

### Search with AI

In addition to regular search, you can use AI to search using natural language. AI will analyze your request, search across your entire workspace, and return the most relevant notes or generate a summary from multiple related notes.

**Suggested prompts:**

- Show my 5 most recent meeting notes.
- What notes did I create this week?
- Find all notes about Machine Learning.
- Which meetings mentioned customer ABC?
- Summarize my Marketing notes from this month.
- What action items are still incomplete?
- What decisions were made in the latest meeting?
- Find notes related to the Product Roadmap.
- Which notes discuss the budget?
- Generate a report from this week's meetings.

## **2. Tips**

To get more accurate results, you can combine multiple search methods.

**Examples:**

- Search by keyword and filter by Source.
- Ask AI to summarize multiple notes on the same topic.
- Search recent notes first, then narrow the results using Tags or Source.

<Callout kind="tip" collapsed="false">
  Combining filters with AI Search helps you find exactly what you need in just a few seconds.
</Callout>

## **3. FAQ: Frequently Asked Questions**

### **Q: Does Smart Search search within transcripts?**

Yes. Smart Search searches note titles, content, transcripts, and summaries.

### **Q: Can I search across multiple notes at the same time?**

Yes. AI can search, analyze, and summarize information from multiple notes across your entire workspace.

### **Q: Does AI Search only return notes?**

No. Besides finding notes, AI can also answer questions, summarize content, and synthesize information from multiple related notes.
