## Poll task result — `GET /v1/create/tasks/{task_id}/result`

| Parameter | In   | Required     | Description                             |
| --------- | ---- | ------------ | --------------------------------------- |
| `task_id` | path | **required** | Task id returned by any create endpoint |

```bash
curl https://api.notexapp.com/v1/create/tasks/<task_id>/result \
  -H "X-API-Key: ntx_live_..."
```

### Responses

Still processing:

```json
{ "status": "PROCESSING" }
```

Completed successfully:

```json
{
  "status": "SUCCESS",
  "data": {
    "note_id": "665f...",
    "title": "Introduction to Machine Learning",
    "summary": "..."
  }
}
```

Failed:

```json
{
  "status": "FAILURE",
  "error": "Unsupported file format"
}
```

### Polling guidance

- Recommended interval: every **3–5 seconds**.
- Most operations complete within **30–120 seconds** depending on source length.
- Stop polling once `status` is `SUCCESS` or `FAILURE`.

### Status values

| Status       | Meaning                              |
| ------------ | ------------------------------------ |
| `PENDING`    | Task queued, not yet started         |
| `PROCESSING` | Task is running                      |
| `SUCCESS`    | Task completed — result is in `data` |
| `FAILURE`    | Task failed — reason is in `error`   |
