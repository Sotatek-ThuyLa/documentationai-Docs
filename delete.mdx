## 1. How to use

### 1.1. Open Recently Deleted

When at least one note is deleted, **Recently Deleted** will appear.

- **Web:** Open **Recently Deleted** from the left sidebar on the **Home** screen

> **Note:** Notes in Recently Deleted are only kept for **24 hours**. After this period, notes will be permanently deleted and cannot be restored.

### 1.2. Restore a note

1. Open **Recently Deleted**.
2. Select the note you want to restore.
3. Click **the three-dot icon on the note (More Options) (...)**.
4. Select **Restore**.
5. The note will be restored to its previous location. If the note belonged to a folder, the system will restore it to its previous location when possible.

### 1.3. Permanently delete a note

If you don't want to keep the note for 24 hours, you can permanently delete it immediately:

1. Open **Recently Deleted**.
2. Select the note you want to delete.
3. Click **the three-dot icon on the note (More Options) (...)**.
4. Select **Delete**.
5. Confirm **Delete**.

After being permanently deleted, the note **cannot be restored**.

### 1.4. Manage multiple notes at once

You can select one or more notes to perform bulk actions:

1. Open **Recently Deleted**.
2. Click **Select notes** at the top-right corner of the screen.
3. Select **2 or more notes:** you can apply **Restore** or **Delete Permanently** to all selected notes.

### 1.5. Check the remaining time

Each note in Recently Deleted will display the remaining time before it is permanently deleted:

- **From 24 hours to 1 hour:** displays the remaining hours, for example `23h`, `12h`, `4h`.
- **Under 1 hour:** displays the remaining minutes, for example `45m`, `15m`, `1m`.
- **Under 1 minute:** displays the remaining seconds and automatically counts down, for example `45s`, `10s`, `1s`.
- When the time reaches `0s`, the note will be automatically permanently deleted and cannot be restored.

---

## 2. Use cases

- **Restore accidentally deleted notes:** Recover notes within 24 hours of deletion.
- **Clean up unnecessary notes:** Permanently delete notes to remove them immediately.
- **Delete multiple notes:** Select multiple notes and perform Restore or Delete Permanently at the same time.
- **Check the remaining time:** Monitor the countdown to know when a note will be permanently deleted.

---

## 3. FAQ: Frequently Asked Questions

### Q: Can I permanently delete a note before 24 hours?

Yes. Select **Delete Permanently** to delete the note immediately. Once confirmed, the note cannot be restored.

### Q: What happens if I don't take any action?

After 24 hours, the system will automatically permanently delete the note. Related data will also be deleted from the storage system.

### Q: Can I restore multiple notes at once?

Yes. Select multiple notes, then select **Restore** to restore them at the same time.

### Q: What happens if I delete a folder containing multiple notes?

The notes will be moved to **Recently Deleted**. When restored, these notes will no longer belong to the deleted folder and will be moved to the **Home** page.
