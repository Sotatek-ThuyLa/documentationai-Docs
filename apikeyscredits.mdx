---
title: Credits
description: |-
  Read your credit balance and quota. Both endpoints accept an API key
  (X-API-Key or Authorization: Bearer ntx_...) or a user JWT.

  Base URL: https://api.notexapp.com
---
## My credits — `GET /v2/credits/me`

Returns the authenticated user's credit information (balance, plan/user type, etc.).

```bash
curl https://api.notexapp.com/v2/credits/me \
  -H "X-API-Key: ntx_live_..."
```

No parameters.

---

## Quota — `GET /v2/credits/quota`

Returns the authenticated user's current quota usage.

```bash
curl https://api.notexapp.com/v2/credits/quota \
  -H "X-API-Key: ntx_live_..."
```

No parameters.
