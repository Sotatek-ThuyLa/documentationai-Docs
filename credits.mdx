## **2. FAQ: Frequently Asked Questions**

### **Q: If I use up all 180 minutes on the Free plan, how can I use the remaining note creation quota?**

Once you have used up all 180 minutes but still have note creation counts left, you will no longer be able to create notes from live recordings or by uploading audio files. You can only create notes using the remaining features (e.g., Input Text, Web links, etc.).

### **Q: If I use up all 15 notes on the Free plan, will my remaining 180 minutes be lost?**

Yes. If you reach the 15-note limit within the month while still having unused minutes, you will not be able to create any more notes. Your quota will reset to 180 minutes and 15 notes at the start of the next month.

### Q: Can I upload a 150-minute audio file to a ProLite account?

No, the maximum file duration limit for the ProLite plan is 120m/note. You should split the file into smaller parts or upgrade to the Pro plan (5h/note) to ensure uninterrupted service.
